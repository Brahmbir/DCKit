## Overview

This section documents DCKit's public API, including the classes and interfaces available for integrating the developer console into your Godot projects.

DCKit exposes functionality for command registration and execution, variable management, console control, and command processing through its autoload singleton and supporting classes.

## API Sections

The reference will be organized into the following areas:

- **DCKit** — Main singleton and public entry points.
- **DCDefinition** — Command definitions, registration, execution, and lifecycle management.
- **DCContext & DCResults** — Argument access, execution context, and command results.

## Usage

For practical examples and integration guidance, see [What is DCKit](/docs/what-is-dckit) and the relevant guides as they become available.

For now, the addon source code and demo project are the primary references for implementation details.
